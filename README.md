# 🚗 Agência Willians - CRUD de Veículos

Aplicação de linha de comando desenvolvida em **Dart**, integrada ao **Supabase**, para realizar o gerenciamento de veículos por meio das operações CRUD (Create, Read, Update e Delete).

## 📌 Funcionalidades

- 🚘 Cadastrar veículos.
- 📋 Listar veículos cadastrados.
- ✏️ Atualizar informações dos veículos.
- 🗑️ Excluir veículos.
- 💰 Exibir valores em reais (R$).
- 🛣️ Exibir quilometragem em quilômetros (km).
- ✅ Validar informações antes de cadastrar ou atualizar.

## 🛠️ Tecnologias utilizadas

- [Dart](https://dart.dev/)
- [Supabase](https://supabase.com/)
- [Interact](https://pub.dev/packages/interact)

- Uma conta no Supabase.

## 🔌 Configurando a conexão com o Supabase

### 1. Criar um projeto

Acesse [Supabase](https://supabase.com/), crie uma conta e depois um novo projeto.

### 2. Criar a tabela de veículos

No SQL Editor do Supabase, execute:

```sql
CREATE TABLE veiculo (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    marca TEXT NOT NULL,
    modelo TEXT NOT NULL,
    ano INTEGER NOT NULL,
    valor NUMERIC(15, 2) NOT NULL,
    quilometragem INTEGER NOT NULL
);
```

### 3. Obter as credenciais

No painel do Supabase, acesse as configurações do projeto e obtenha:

- Project URL
- Publishable Key

### 4. Configurar o arquivo .env

Na raiz do projeto, crie um arquivo chamado `.env`.

Adicione as seguintes variáveis:

```env
SUPABASE_URL=https://SEU-PROJETO.supabase.co
SUPABASE_PUBLISHABLE_KEY=SUA_CHAVE_PUBLICAVEL
```

Substitua os valores de exemplo pelas credenciais do seu projeto.

**Importante:** nunca compartilhe seu arquivo `.env` nem envie credenciais privadas para o GitHub. O projeto utiliza a chave publicável do Supabase. Não utilize a chave `service_role` no aplicativo.

### 5. Configurar o acesso à tabela

Se a opção de Row Level Security (RLS) estiver habilitada, configure políticas adequadas para permitir as operações de leitura, inserção, atualização e exclusão.

Não deixe a tabela publicamente acessível em um projeto com dados reais. Configure as permissões de acordo com a autenticação e as necessidades da aplicação.

## 📦 Instalando as dependências

Abra o terminal na raiz do projeto e execute:

```bash
dart pub get
```

Esse comando instala as dependências declaradas no arquivo `pubspec.yaml`.

## ▶️ Executando o projeto

Na raiz do projeto, execute:

```bash
dart run bin/main.dart
```

Após a execução, o menu interativo será apresentado no terminal.

## 🔒 Segurança

O arquivo `.env` contém informações de conexão e não deve ser enviado ao repositório.

O `.gitignore` deve conter:

```gitignore
.dart_tool/
.env
```

Para disponibilizar um exemplo de configuração, utilize o arquivo `.env.example`:

```env
SUPABASE_URL=
SUPABASE_PUBLISHABLE_KEY=
```

Assim, outras pessoas poderão configurar suas próprias credenciais sem ter acesso às suas chaves.
